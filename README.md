## Main project — CandidLyzer

[CandidLyzer](https://candidlyzer.com) is a job application tracker and
career analytics platform built for tech job seekers.

Instead of treating the job search as an unstructured list of applications,
CandidLyzer turns each application into useful data. It helps users understand
where their search is losing momentum and what they should improve next.

### What CandidLyzer does

- Keeps job applications in a structured and searchable pipeline.
- Tracks responses, interviews, offers, sources, and conversion rates.
- Identifies bottlenecks inside the application funnel.
- Compares the performance of different application sources.
- Generates job-search forecasts and diagnostic signals.
- Produces focused AI coaching reports with practical next actions.
- Parses supported job pages into clean application records.
- Provides Free and Pro plans through secure Stripe subscriptions.

### Production engineering

CandidLyzer is built as a real production SaaS rather than a static portfolio
project. Its engineering includes:

- secure cookie-based authentication;
- refresh-token family protection;
- Google OAuth with PKCE;
- PostgreSQL persistence and migrations;
- Redis-backed distributed rate limiting;
- Stripe Checkout and subscription lifecycle management;
- idempotent and order-protected Stripe webhooks;
- end-of-period subscription cancellation;
- Resend password-reset and feedback email delivery;
- OpenAI-powered coaching reports;
- a dedicated Rust analytics service;
- health and readiness endpoints;
- browser end-to-end testing;
- automated production deployments;
- responsive desktop and mobile interfaces.
